# FlyRank AI Backend Internship: Assignment BE-01

## Build Your First API Endpoint
This repository contains a minimal backend server built using **Express.js** as part of the Backend AI Engineering track for the FlyRank AI Internship. 

The objective of this assignment was to step onto the server-side of the request-response loop by building a lightweight backend and testing it.
## What I Did In This Task
* **Initialized an Express server:** Set up a clean, minimal Node.js server with Express.js.
* **Created Two JSON Endpoints:** Built two functional routes that handle incoming HTTP GET requests and serve JSON responses.
* **Tested via Browser:** Verified that the request-response loop functions properly by calling and testing both endpoints directly inside the web browser.

## Tech Stack
* **Runtime:** Node.js
* **Framework:** Express.js
